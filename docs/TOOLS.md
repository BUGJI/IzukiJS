# Izuki JS · 工具与权限说明

## 底部导航

- **首页**：运行状态（运行中脚本 / 停止 / 运行最近脚本）、脚本数量、控制模式状态、最近日志。
- **脚本中心**：新建 / 导入 / 重命名 / 导出 / 删除；布局分析、定时任务入口。
- **日志**：内存日志 + 文件占用，可清空。
- **设置**：控制模式优先级、悬浮窗、持续录屏、调试悬浮窗、日志存储、版本。

## 控制模式与权限

进入「首页右上角齿轮」或「控制模式」页配置四种后端：

| 模式 | 开启方式 | 「撤销权限」行为 |
|---|---|---|
| 无障碍 | 跳转系统无障碍设置开启 | 程序化 `disableSelf()` 关闭 |
| Shizuku | 「去授权」→ Shizuku 弹窗授权 | 断开后端并跳转 Shizuku 应用 |
| Root | 「检测 Root」→ su 授权 | 撤回后端（彻底撤销去 Magisk） |
| 蓝牙 HID | 「去连接」→ 扫描并连接数位板狗 | 断开并清除记忆设备 |

> 页面顶部提示：**脚本运行时可以收回非必要权限，以降低被风控识别的风险**。只保留当前脚本真正需要的模式。

脚本内可用 `permissions.*` 查询（见 `docs/SCRIPT_API.md`）。

## 持续录屏（无限截图）

用于绕开无障碍截图（API30+ 限制）与反复授权：

1. 设置 → 「持续录屏（截图）」→ **授权并开始**（系统录屏弹窗，仅一次）。
2. 之后保持前台服务常驻，`ScreenCapture` 持续持有 `MediaProjection + VirtualDisplay + ImageReader`。
3. `captureScreen()` / `images.*` / `ocr.*` 会**优先**使用录屏帧。
4. 需要时可点 **停止录制**。

说明：
- Android 14+ 要求先启动 `mediaProjection` 类型前台服务再调用 `getMediaProjection`，本实现已遵循。
- 服务使用 `START_STICKY` 常驻，不会主动停止；若被系统或用户中断，会收到回调并清理，需重新授权。
- 录屏期间会有常驻通知。

## 调试悬浮窗

设置 → 「调试悬浮窗」开启。面板可拖动，包含：

- **布局**：读取无障碍控件树，按层级列出 className / viewId / text / 可点标记，并显示每个节点的中心坐标 `@(x,y)`。
- **OCR**：对当前屏幕运行 OCR，输出**每个识别元素的坐标** `[x,y 宽x高] 文字`。
- **清空**：清除输出与叠加层。

抓取与识别时会**自动隐藏面板**（`INVISIBLE` + 等待一帧）后再截图，避免把悬浮窗内容截入画面。

**识别结果叠加**：OCR 完成后，会用一层全屏透明叠加层在每个识别元素的位置绘制方框与 `(x,y)` 标签，约 6 秒后自动消失。

## OCR 本地 / 在线

设置 → 「OCR 识别」，按设备情况路由，脚本无感知：

- **本地 (MLKit)**：端侧离线，隐私好、不耗流量，但占用设备算力。
- **在线**：把图片发给云端，适合低端设备；在线失败会自动回退本地。

在线服务商预设：

| 服务商 | 需要的配置 | 说明 |
|---|---|---|
| 百度 OCR | API Key、Secret Key | 自动换取 access_token 后调用通用文字识别 |
| Google Vision | API Key | 调用 `images:annotate` 的 `TEXT_DETECTION` |
| 自定义 | 请求地址、鉴权 Header 名/值 | POST JSON `{"image":"<base64>"}`，返回 `text`/`result` 字段或纯文本 |

需要 `INTERNET` 权限（已声明）。Baidu / Google 返回逐元素坐标，可用于 `ocr.find()` 与调试叠加显示。

## 悬浮窗控制条

设置 → 「显示悬浮控制条」开启（需「显示在其他应用上层」权限）。可拖动的小条：显示就绪/运行中状态，`▶` 运行最近脚本，`✕` 关闭。

## 布局分析器

脚本中心 → 「布局分析」图标进入：

- 截取屏幕截图并叠加控件边框（可点节点高亮）。
- 点选节点查看 className / id / text / desc / bounds，并**自动生成选择器代码**（`selector.clickById(...)` 等）可一键复制。
- 无截图权限时降级为节点列表。

## 定时任务

脚本中心 → 溢出菜单「定时任务」：

- 选择脚本 + 触发时间（时:分）+ 重复间隔（分钟，0 = 仅一次）。
- 使用 `AlarmManager`（精确/非精确自动降级），开机后自动重新注册。

## AI Agent

设置 → 「AI Agent」（脚本中心外独立页面）配置脚本「脱困」所用的模型：

- **接口**：Base URL、API Key、模型、自定义鉴权 Header，兼容任意 OpenAI Chat Completions 服务（OpenAI / DeepSeek / 通义 / one-api / Ollama 等）。API Key 与 Header 值使用 Android Keystore 加密存储。
- **生成参数**：流式返回、Temperature、最大 Token、超时。
- **Agent 工具**：是否启用工具调用、是否允许 Shell（默认关闭）、默认最大步数（脚本可在调用时覆盖）。
- **系统提示词**：框架基础提示词，描述运行环境、可用工具与决策规范，可「恢复默认」。
- **连接测试**：发送一条极短请求验证配置。

脚本侧接口见 `docs/SCRIPT_API.md` 的 `ai` 一节。

## 日志存储

设置 → 「日志存储」：

- **自动清理**开关。
- **最大存储**：1 / 5 / 10 / 20 MB（超出后保留最近一半）。
- **保留天数**：1 / 3 / 7 / 30 天。
- 显示当前占用，支持「立即清空」。

日志同时写入 `filesDir/logs/app.log`，格式为 `时间戳|级别|内容`。
