# Izuki JS · 工具与权限说明

## 底部导航

- **运行**：运行状态（运行中脚本 / 停止 / 运行最近脚本）、脚本数量、权限与能力状态、最近日志。
- **脚本中心**：新建 / 导入 / 重命名 / 导出 / 删除，支持按名称 / 标签搜索与标签编辑；布局分析、定时任务入口。
- **日志**：内存日志 + 文件占用，可清空。
- **设置**：通用（外观、语言、编辑器）、自动化（控制后端、识别与截图、脚本运行、悬浮窗与虚拟屏、环境变量）、扩展（AI Agent、MCP 服务）、安全（权限与能力、安全解锁）、数据（日志、录制管理、备份与恢复）、关于与更新。

## 权限与能力（授权）

从「运行 → 权限与能力 → 配置」进入。该页集中所有需要用户显式授权的项，**按授权复杂度排序（简单项在前）**，用维度标签（精准度 / 风控 / 授权成本）与优缺点标注核心权限：

- **核心权限**：蓝牙 HID、无障碍、Shizuku、无线调试、Root（可直接控制设备，标注优缺点）。
- **辅助权限**：屏幕捕获（需配合核心权限才有意义；标注搭配建议与优缺点）、通知监听、使用情况访问、全部文件访问等系统授予项。
- **附加能力**：应用列表、脚本网络、后台保活等用户级开关。
- 运行超时、保持唤醒、快捷磁贴与悬浮窗已统一迁入「设置」页，不再出现在本页。

| 权限 | 精准度 | 风控风险 | 授权成本 | 主要能力 |
|---|---|---|---|---|
| 屏幕捕获 | 高 | 中 | 简单（一键） | 截图（供找图 / OCR） |
| 蓝牙 HID | 高 | 极低 | 中（需硬件） | 手势 / 键盘 / 文本 |
| 无障碍 | 高 | 高 | 简单 | 手势 / 文本 / 控件树 / 截图(API30+) |
| Shizuku | 高 | 中 | 复杂（需常驻服务） | 手势 / 按键 / 文本 / 截图 / Shell |
| 无线调试 | 高 | 中 | 中（Android 11+，配对一次） | 同 Shizuku（Shell 级，不含虚拟屏 / 特权解锁） |
| Root | 高 | 中 | 复杂（需 Root） | 同 Shizuku + 系统级操作 |
| 通知监听 | 高 | 低 | 简单 | 读通知 / 等待新通知 / 清除（`notify.*`） |
| 使用情况访问 | 高 | 低 | 简单 | 前台应用 / 使用时长（`app.foreground/usageStats`） |
| 应用列表 | — | 低 | 简单（开关） | 枚举已安装应用（`app.list`，`QUERY_ALL_PACKAGES`） |
| 全部文件访问 | — | 中 | 简单 | 读写共享存储任意路径（`fs.*`） |
| 脚本网络 | — | 中 | 简单（开关） | 脚本发起 HTTP(S) 请求（`http.*`），可配域名白名单 |

> 页面顶部提示：**脚本运行时可以收回非必要权限，以降低被风控识别的风险**。按标注的优缺点只保留当前脚本真正需要的项。

脚本内可用 `permissions.*` 查询控制模式就绪状态（见 `docs/SCRIPT_API.md`）。

### 屏幕捕获（持续录屏 / 无限截图）

用于绕开无障碍截图（API30+ 限制）与反复授权：

1. 权限与能力 → 「屏幕捕获」→ **授权并开始**（系统录屏弹窗，仅一次）。
2. 之后保持前台服务常驻，`ScreenCapture` 持续持有 `MediaProjection + VirtualDisplay + ImageReader`。
3. `captureScreen()` / `images.*` / `ocr.*` 在虚拟屏目标下使用虚拟屏帧；否则**优先**使用录屏帧。
4. 需要时可点 **停止录制**。

> 辅助权限：建议配合 蓝牙 HID / 无障碍 / Shizuku 等控制权限，形成「看屏 + 操作」闭环。

说明：
- 只读屏、不注入输入，风控风险低；一次授权常驻，免去反复弹窗。
- Android 14+ 要求先启动 `mediaProjection` 类型前台服务再调用 `getMediaProjection`，本实现已遵循。
- 服务使用 `START_STICKY` 常驻，不会主动停止；若被系统或用户中断，会收到回调并清理，需重新授权。
- 录屏期间会有常驻通知。

### 控制模式

配置五种后端（按复杂度排序）：

| 模式 | 开启方式 | 「撤销权限」行为 | 风控风险 |
|---|---|---|---|
| 蓝牙 HID | 「去连接」→ 扫描并连接数位板狗（[固件仓库](https://github.com/BUGJI/IzukiJS_HID)） | 断开并清除记忆设备 | 极低 |
| 无障碍 | 跳转系统无障碍设置开启 | 程序化 `disableSelf()` 关闭 | 高 |
| Shizuku | 「去授权」→ Shizuku 弹窗授权 | 断开后端并跳转 Shizuku 应用 | 中 |
| 无线调试 | 「去连接」→「开始配对（通知输入）」→ 在通知栏输入配对码 | 断开后端或在设置页「忘记配对」删除本地身份 | 中 |
| Root | 「检测 Root」→ su 授权 | 撤回后端（彻底撤销去 Magisk） | 中 |

### 后台虚拟屏 / 画中画

「设置 → 悬浮窗与虚拟屏 → 后台虚拟屏」：

- **允许后台虚拟屏**：需要 Android 10+ 与 Shizuku 授权；允许后脚本可通过
  `@env RUN_MODE=background` 或 `virtualScreen.start()` 使用后台模式。未授权时开关下方提供
  「前往授权」入口，可直接跳转到「权限与能力」。
- **默认运行模式**：前台 / 后台虚拟屏；未指定 `RUN_MODE` 的脚本按此运行。
- **后台分辨率**：默认使用「设备」档位，按当前设备方向读取真实宽高与密度；长边超过
  1920 时等比缩小并同步缩放 dpi，保持逻辑 dp 尺寸不变。另内置 720P（1280×720@240）与
  1080P（1920×1080@280），也可自定义宽 / 高 / dpi。PiP 宽高比会按实际分辨率自动 clamp
  到系统允许范围。
- **后台运行时自动画中画**：停在「运行」页按 Home 时，应用缩为系统画中画并继续显示
  虚拟屏画面；小窗只读，无法在小窗内操作。
- 目标应用已在主屏运行时，后台启动会先强停再迁移到虚拟屏；启动后不做周期离屏看护。
- 虚拟屏激活后，截图 / 找图 / OCR / 点击默认自动定向到虚拟屏；可用
  `virtualScreen.target('main')` 临时切回主屏，或 `captureScreen(path, 'main'|'virtual')`
  一次性指定捕获来源。虚拟屏截图会等待最多 1 秒首帧。
- 虚拟屏上不支持 `selector.*` / 无障碍控件树，请改用 `capture` / `ocr` / 坐标输入。
- 脚本结束时会自动销毁本次创建的虚拟屏；`virtualScreen.stop()` 可在脚本内提前释放。
- 虚拟屏采集与 PiP 预览都在 App 进程内完成；Shizuku 特权服务只负责创建/销毁
  `VirtualDisplay`、拉起目标应用与查询虚拟屏前台包名。

### 悬浮窗

「设置 → 悬浮窗与虚拟屏」开启（需「显示在其他应用上层」权限）：

> 辅助权限：建议配合任意控制权限使用，便于运行脚本与调试。

- **脚本日志悬浮窗**：默认在脚本运行时**自动展开显示**，可在「设置 → 悬浮窗与虚拟屏 → 悬浮控制条」选择「不弹出 / 折叠显示 / 展开显示」。默认展示 INFO 及以上级别的日志（`I` / `✓` / `W` / `E` 前缀，按级别着色）。可拖动标题栏移动；`—` 最小化（折叠日志区域），`■` 停止脚本（未运行时关闭悬浮窗）。脚本结束后自动关闭。
  - 选择「折叠显示」时只保留标题栏、停止与展开按钮，避免日志区域遮挡屏幕。
  - 选择「不弹出」后运行时不再自动拉起；仍可在本页手动开启。脚本保活由运行通知负责，不受影响。
  - 若手动开启该开关，则悬浮窗**常驻**显示，脚本结束后也不自动关闭。
  - 脚本进行任何截图（找图 / 找色 / OCR / `captureScreen` / AI）时会**自动隐藏**，截图完成后恢复，避免把悬浮窗内容截入画面。
  - 脚本执行触摸注入（`click` / `longClick` / `swipe` / 手势 / 控件坐标点击）时同样**自动隐藏**，注入完成后恢复，避免点击落在悬浮条上而非目标应用。连续操作用同一隐藏状态，最后一次操作后约 300ms 恢复，避免闪烁。输入打到后台虚拟屏时不隐藏（与主屏悬浮窗不重叠）。
- **显示布局 / OCR 调试面板**：可拖动面板，包含：
  - **布局**：读取无障碍控件树，按层级列出 className / viewId / text / 可点标记，并显示每个节点的中心坐标 `@(x,y)`。
  - **OCR**：对当前屏幕运行 OCR，输出**每个识别元素的坐标** `[x,y 宽x高] 文字`。
  - **清空**：清除输出与叠加层。

调试面板抓取与识别时也会**自动隐藏面板**（`INVISIBLE` + 等待一帧）后再截图，避免把悬浮窗内容截入画面；脚本执行截图或触摸注入时，调试面板也会随脚本日志悬浮窗一起临时隐藏。

**识别结果叠加**：OCR 完成后，会用一层全屏透明叠加层在每个识别元素的位置绘制方框与 `(x,y)` 标签，约 6 秒后自动消失。

### 通知监听 / 使用情况访问 / 应用列表 / 全部文件访问

均在「权限与能力」页以开关控制（脚本 API 见 `docs/SCRIPT_API.md`）：

- **通知监听**：开启「通知使用权」后，脚本可用 `notify.*` 读取通知标题 / 内容 / 包名、
  等待新通知、清除通知（只读，不点击、不回复）。
- **使用情况访问**：读取前台应用与使用时长，供 `app.foreground()` / `app.lastUsed()` /
  `app.usageStats()` 使用。
- **应用列表**：一项应用层开关（对应 `QUERY_ALL_PACKAGES`），控制脚本能否用 `app.list()` /
  `app.info()` / `app.isInstalled()` 枚举已安装应用。
- **全部文件访问**：让 `fs.*` 与 `captureScreen(path)` / `images.findImage(path)` 能读写共享
  存储中的任意路径；未授权时仅应用私有目录与部分公共目录可用。
- **脚本网络（HTTP）**：默认关闭。开启后脚本可用 `http.*` 发起 HTTP(S) 请求；建议填写
  域名白名单（逗号分隔，留空表示不限制，填写后允许这些主机及其子域）。单次响应体上限 2 MB。

### 通知与进度

「设置 → 脚本运行 → 通知」：

- **启用进度通知**（默认开）：允许脚本通过 `notify.progress` 更新运行通知的标题、正文、
  阶段、进度、分段、颜色与图标。关闭后 `notify.progress` 返回 `false`，运行通知仍保留。
- **通知权限**：Android 13+ 需要 `POST_NOTIFICATIONS`；未授权时进度通知不会显示，
  可在同一分组内请求授权。
- 运行通知始终保留（Android 前台服务要求），只会在开启进度通知时应用进度样式；
  低版本系统自动降级为普通进度条。

### 通知系统（设置 → 通知）

- **脚本消息**：脚本用 `// @need push` + `push.send()` 主动发送；不需要通知使用权。
- **运行结果**：手动（界面 / 磁贴）、自动（定时 / 编排 / MCP）结果统一通知；
  默认仅失败，可改为全部；编排默认只发一条汇总，可开启逐步通知。
- **渠道**：本地系统通知、Webhook、Bark、Telegram、ntfy；每个渠道可单独设最低级别、
  接收事件与标签过滤，并支持「发送测试」。渠道密钥经 Keystore 加密保存，随配置备份导出。
- Android 13+ 仍需 `POST_NOTIFICATIONS`；本地渠道未授权时只影响系统通知，远程推送不受影响。

### 保持唤醒 / 运行超时（设置 → 脚本运行）

在「设置 → 脚本运行」中配置：

- **保持唤醒**（默认开）：脚本运行期间持有 `WAKE_LOCK`，避免脚本跑一半因息屏 / 休眠中断；
  定时任务触发时同样生效。
- **同时点亮屏幕**：运行脚本时唤醒屏幕。
- **允许设备在锁定时自主解锁**（默认关，在「设置 → 安全解锁」中配置）：
  手动运行与定时任务触发前，先唤醒屏幕并尝试收起锁屏。支持 Shizuku / Root；无线调试提供 Shell 回退，
  可靠性低于 Shizuku。可选滑动、PIN 或锁屏录制。「设置 → 安全解锁」底部会汇总 MCP 的解锁工具与
  操作前自动解锁状态，并可直接跳转到 MCP 服务设置。
  - **测试解锁**：会先主动锁屏，再走完整解锁链路；请确保当前凭据正确，否则需要手动解锁。
  - **锁屏录制**：点击「录制图案」后会自动锁屏并点亮屏幕，使用 `getevent` 读取真实触摸
    事件，直到设备解锁进入系统后自动结束。支持图案、连续手势与多次点击（如 PIN 键盘点击），
    结果按屏幕归一化坐标保存，换分辨率后仍可回放。
  - PIN 仅支持数字，使用 Android Keystore 加密保存，不写入日志，也不参与自动备份。
  - 锁屏录制依赖 `getevent` 与触摸设备权限；部分 ROM 可能不支持，失败时建议改用 PIN。
  - 输错凭据可能触发系统限流或清空，请仅在自己拥有的设备上使用。
  - 定时任务若设置了「已解锁」条件且解锁失败，会按条件不满足跳过；其他任务继续运行并记录警告。
- **运行超时**（默认不限制）：超过设定时长（10 / 30 / 60 / 120 分钟）后自动中断脚本。
  超时与手动「停止」都会通过 QuickJS 中断回调打断执行，因此 `while (true) {}` 这类
  纯计算死循环也能被终止；若中断回调不可用（例如原生库缺失），则退化为在
  `sleep` / 等待 / 原生调用返回时停止。

### 快捷磁贴

在**脚本中心**对某个脚本选择「钉到磁贴」，再到系统快捷设置中手动编辑并添加「Izuki 脚本」
磁贴（本应用会给出提示，部分系统可能不弹自动添加引导）。

- 点击磁贴：脚本运行中 → 停止；空闲 → 运行已钉选的脚本。
- 未钉选脚本、或在「设置 → 脚本运行 → 快捷磁贴」中关闭「启用快捷磁贴」时，磁贴显示为不可用。

### 录制管理（设置 → 录制管理）

脚本通过 `record.start()` / `record.stop()` 产生的录制保存在应用私有目录。该页显示每条录制的
时间、帧数与占用，可删除单条或清空全部；录制进行中时禁止删除与清空。录制文件属于用户数据，
不随配置备份导出，也不包含在「恢复默认设置」中。开始用户录制前可填写名称，详情页也可重命名；
详情页按缩略图尺寸解码，并可分页加载更多事件。帧数达到上限后旧帧会标记为已截断，
被系统杀进程的录制会显示「未正常结束」并按事件文件重建统计。

- **格式 v2**：每个事件带 `seq` / `atMs` / `elapsedMs` / `ok`，截图与控件上下文是独立事件；
  `pipeline.replay(..., {strict:true})` 会严格按录制顺序消费截图与动作。
- **用户录制**：Shizuku 路径支持多指手势 / 多指滑动；Shell `getevent` 回退只保证单指。
  命中控件通过异步上下文补全，不阻塞触摸采集。
- **最大帧数 / JPEG 质量**：可在「设置 → 开发者选项 → 录制」中调整；默认最多 800 帧、质量 88。

## 设置 · 控制后端与识别

设置 → 「控制后端 / 识别与截图」，用于调整不需要授权的偏好。

### 读取 / 操作优先级（控制后端）

- **全局优先模式**：当某项能力有多个后端可用时，优先使用选中的模式；可设为「自动」。
- **按能力指定优先模式**：为不同能力分别指定后端，未指定的跟随全局；仅列出至少有两个可用后端的项。
- **控制后端**：开关某后端是否参与能力协商；已建立的连接（如无障碍服务、Shizuku）本身不受影响。
- 授权与撤销在「权限与能力」页进行；控制后端卡片底部提供「前往权限与能力」入口，未就绪时可直接跳转。

### 截图压缩

影响「保存截图」的文件大小与在线 OCR 的上传流量；图像匹配、找色与本地识别仍使用原始分辨率，坐标不受影响。

- **缩放比例**：100 / 75 / 50 / 25%。
- **JPEG 质量**：60 / 75 / 90 / 100。

### OCR 本地 / 在线

按设备情况路由，脚本无感知：

- **本地 (MLKit)**：端侧离线，隐私好、不耗流量，但占用设备算力。
- **在线**：把图片发给云端，适合低端设备；在线失败会自动回退本地。

在线服务商预设：

| 服务商 | 需要的配置 | 说明 |
|---|---|---|
| 百度 OCR | API Key、Secret Key | 自动换取 access_token 后调用通用文字识别 |
| Google Vision | API Key | 调用 `images:annotate` 的 `TEXT_DETECTION` |
| 自定义 | 请求地址、鉴权 Header 名/值 | POST JSON `{"image":"<base64>"}`，返回 `text`/`result` 字段或纯文本 |

需要 `INTERNET` 权限（已声明）。Baidu / Google 返回逐元素坐标，可用于 `ocr.find()` 与调试叠加显示。

## 脚本能力声明

脚本可在头部用 `// @need shell, fs` / `// @need http` 声明需要的高风险命名空间。
声明后运行时会隐藏未声明的 `shell` / `fs` / `notify` / `push` / `http` / `clipboard` / `ai` /
`app` / `selector` / `images` / `ocr` / `virtualscreen`；没有声明时保持旧行为（暴露全部已启用能力）。
未知能力名会拒绝运行，缺少前置条件（如 `http` 未启用、Shizuku / 无线调试 / Root 未就绪）会在日志中提示。

## 脚本编辑

- **API 补全**：输入 `app.` / `selector.` / `http.` 等命名空间或函数前缀时，编辑器底部
  会出现候选，点击即可插入；候选覆盖全局函数与各命名空间的常用方法。
- **标签**：脚本中心条目菜单 →「编辑标签」，逗号分隔；搜索框同时匹配名称与标签。
  右上角菜单可切换「不分组 / 按标签分组」；分组视图按标签名排序，多标签脚本会出现在
  每个标签组中，无标签脚本归入最后的「未分类」组。
  重命名 / 删除 / 撤销删除时会同步迁移或清理标签。
- **版本历史**：编辑器右上角菜单 →「版本历史」。每次保存前自动把旧内容留档到应用私有
  目录（10 分钟节流，每个脚本最多 20 个版本），可查看时间 / 首行预览并一键恢复；
  恢复前会强制保存当前内容，避免覆盖丢失。
- **调试**：右上角菜单 →「从光标处运行」（当前行到脚本末尾）与「变量与状态」
  （查看 `env` / `state` 持久化值；不是 JS 局部变量调试器）。

## 布局分析器

脚本中心 → 「布局分析」图标进入：

- 截取屏幕截图并叠加控件边框（可点节点高亮）。
- 点选节点查看 className / id / text / desc / bounds，并**自动生成选择器代码**（`selector.clickById(...)` 等）可一键复制。
- 无截图权限时降级为节点列表。

## 定时任务

脚本中心 → 溢出菜单「定时任务」：

- **触发方式**：定时（每天某个时刻，仅一次）、间隔（首次时间 + 每 N 分钟）、Cron
  （五段式：分 时 日 月 周，支持 `*` / 范围 / 步长 / 列表与 `@daily` 等别名）、事件
  （充电、Wi-Fi 连接、解锁）。
- **附加条件**：充电中、Wi-Fi、已解锁、指定前台应用包名；全部满足才会执行。
- **失败重试**：设置重试次数与间隔（分钟）；超时 / 运行错误会按该策略重试，
  条件不满足或手动停止不会消耗重试次数。
- 时间 / Cron 使用 `AlarmManager`（精确/非精确自动降级），事件通过广播与 Wi-Fi 回调触发；
  开机后自动重新注册。Cron 的「日」与「周」同时受限时按「同时满足」处理。
- 事件触发有 60 秒去抖；Wi-Fi 事件在应用进程存活时通过系统网络回调监听。
- 「指定前台应用」条件依赖无障碍 / 使用情况访问 / Shizuku 中任一可用的前台包名来源；
  都不可用时该条件会判定为不满足。

## AI Agent

设置 → 「AI Agent」（脚本中心外独立页面）配置脚本「脱困」所用的模型：

- **接口**：Base URL、API Key、模型、自定义鉴权 Header，兼容任意 OpenAI Chat Completions 服务（OpenAI / DeepSeek / 通义 / one-api / Ollama 等）。API Key 与 Header 值使用 Android Keystore 加密存储。
- **生成参数**：流式返回、Temperature、最大 Token、超时。
- **Agent 工具**：是否启用工具调用、是否允许 Shell（默认关闭）、默认最大步数（脚本可在调用时覆盖）。
- **系统提示词**：框架基础提示词，描述运行环境、可用工具与决策规范，可「恢复默认」。
- **连接测试**：发送一条极短请求验证配置。

脚本侧接口见 `docs/SCRIPT_API.md` 的 `ai` 一节。

## MCP 服务

设置 → 「MCP 服务」，把本机的读屏与控制能力作为 MCP 工具暴露给外部 AI 客户端：

- **服务开关**：启用后常驻前台服务并显示访问地址；再次打开 App 会自动恢复。
- **访问令牌**：所有请求需 `Authorization: Bearer <令牌>`，令牌经 Keystore 加密存储，可重新生成。
- **监听范围**：仅本机（默认，配合 `adb forward`）或局域网；端口可调。
- **工具开关**：读屏 / 控制工具默认可用；`shell`、脚本执行与解锁默认关闭，需显式开启。
  解锁还要求「设置 → 安全解锁」已启用并配置凭据，可选暴露 `unlock` 工具或在主屏操作前自动解锁。
  `允许 Shell` 下方会显示 Shizuku / Root 后端是否就绪，未就绪时可跳转到「权限与能力」授权。
- **客户端配置**：一键复制连接地址与配置 JSON；stdio 客户端可用 `mcp-remote` 桥接。

客户端配置、工具 / 资源清单与排障详见 [`MCP.md`](MCP.md)。

## 日志

设置 → 「日志」：

- **自动清理**开关。
- **最大存储**：1 / 5 / 10 / 20 MB（超出后保留最近一半）。
- **保留天数**：1 / 3 / 7 / 30 天。
- 显示当前占用，支持「立即清空」。

日志同时写入 `filesDir/logs/app.log`，格式为 `时间戳|级别|内容`。
